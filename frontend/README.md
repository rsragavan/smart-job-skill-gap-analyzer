# Frontend

This package is the React 19 + TypeScript + Vite + Material UI client for **Smart Job Skill Gap Analyzer**.

## Scripts

```bash
npm install
npm run dev      # development server
npm run build    # tsc -b && vite build
npm run preview  # preview production build
```

Set `VITE_API_URL` in `.env` (see `.env.example`).

Project documentation lives in the repository root [`README.md`](../README.md) and [`docs/`](../docs/).
